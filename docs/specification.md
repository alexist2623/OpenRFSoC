# 초기 목표와 미정 사항

## 사용자와 합의한 목표

- Xilinx RFSoC 기반 제어기를 MPW 제작 가능한 ASIC으로 옮긴다.
- RISC-V 계열 CPU를 사용한다. 자체 RTL과 무상 오픈소스 IP를 허용한다.
- 상용 AXI IP 구매는 제외한다.
- DAC를 칩 안에 통합한다. 2026-11-09에 목표를 2채널, 채널당 14-bit 입력,
  2 GSPS, 아날로그 출력 대역 약 500 MHz까지로 구체화했다.
- 가능하면 약 1 GSPS ADC도 포함한다. ADC 채널 수는 아직 확정되지 않았다.
- 첫 칩은 동작 확인을 우선한다.

## 아직 확정하지 않은 항목

- ADC 비트 수와 주파수 범위, DAC/ADC의 ENOB·SFDR, 전압 범위와 부하.
  DAC의 14-bit 입력 폭은 확정 목표이나 14 ENOB 또는 특정 SFDR을 합의한 것은 아니다.
- 소비전력, 클록 지터, 채널 동기화 정확도, 테스트 핀과 패키지.
- CPU 구현과 ISA 확장, 메모리 맵, SRAM 용량과 외부 메모리 필요 여부.
- 사용자는 SKY130을 선호한다. 현재 SKY130 DAC 타당성 프로토타입을 평가 중이며,
  최종 공정·MPW 프로그램·패키지와 실제 제출 규칙은 아직 확정하지 않았다.
- 이전 대화의 8-bit DAC, 6-bit ADC와 SRAM 64 KiB는 설계 제안이며 확정 사양이 아니다.

## 첫 기능 검증 경로

레지스터 쓰기 → 이벤트 큐 → 타임스탬프 비교 → 두 채널 파형 출력.
ADC는 별도의 캡처 버퍼와 테스트 경로를 마련한다. 현재 저장소에는 이 경로의
구현이 아직 없다. 개발 도구 점검용 카운터·RC와 별도로
`analog/dac14_2g/`의 한 채널 DAC 초기 회로 및 세그먼트 decoder를 추가했다.
실제 고속 직렬화·클록·드라이버·보정·레이아웃 구현은 아직 포함하지 않았다.

14-bit 샘플을 2채널에 2 GSPS로 공급하는 순수 대역폭은 56 Gbit/s = 7 GB/s다.
16-bit 저장 형식이면 8 GB/s다. 250 MHz에서 채널별 8샘플을 처리하는 구조는
대역폭 계산상의 후보이며, 해당 디지털 클록의 SKY130 타이밍 달성을 뜻하지 않는다.
메모리 공급, 고속 직렬화와 아날로그 동작을 각각 검증해야 한다.

## 단계별 완료 기준

1. 환경: RTL 시뮬레이션, 합성, SPICE와 작은 RTL-to-GDS 예제를 재현한다.
2. 디지털: 이벤트 큐, 128-bit 이벤트의 staging/commit, reset과 backpressure를 검증한다.
3. 아날로그: 선택한 PDK에서 DAC 셀과 ADC 샘플링·비교 회로를 평가한다.
4. 통합: RISC-V와 버스, SRAM, 변환기 모델을 연결한다.
5. 물리 검증: 실제 매크로를 통합하고 공정·전압·온도, 기생 성분, DRC/LVS,
   타이밍, 전원과 테스트 경로를 검증한다. 파운드리 제출 조건을 별도로 확인한다.
